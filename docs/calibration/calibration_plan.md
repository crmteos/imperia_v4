# План Kaliбрування Контекстів та Синтезу Артефактів (Imperia v4)

## 📌 Мета полігону
Ізольована розробка математичних поличок, накопичення JSON-артефактів занурень та їх очищення через Гармонійний (Косinus) Фільтр перед підключенням до Supabase та канонічного ядра.

---

## 📖 ТЕРМІНОЛОГІЧНИЙ КАНОН СИСТЕМИ
* **Домен Джерела (Domain)**: Суцільне контекстне поле, яке адресовано через Носія Знань, Філософсько-математичну школу або Першоджерело (наприклад, *Домен Шмакова, Домен Пенроуза, Домен «Катехизис»).
* **Математична Проекція (Projection)**: Конкретні формули, шкали, матриці та геометричні конструкти, які витягуються з відповідного Домену Джерела для побудови системных поличок.

---

## 🛡️ ДВОФАЗНИЙ ПРОТОКОЛ НАКОПИЧЕННЯ ТА ОЦІНКИ (Захист від Q-decay)

### **Фаза 1: Накопичення та Оцінка «Кислотності» (Поточний етап)**
1. Послідовне внесення Доменів Джерел до загального реєстру без виконання негайних занурень.
2. Оцінка кожного ДомENU за двома ключовими параметрами:
   * **«Рівень кислотності» (Anthropomorphic Noise Level)** — насиченість метафорами, суб'єктивним шумом та гуманітарними конструктами.
   * **«Математична готовність» (Math Shield Requirement)** — необхідний математичний апарат, який має бути побудований *до* занурення у дане середовище.
3. Впорядкування Доменів у градієнтну лінійку: **від низької кислотності (чиста математика/фізика)** ➔ **до високої (гуманітарні/соціальні стани)**.

### **Фаза 2: Затвердження та Покрокові Занурення**
Тільки після повного формування, оцінки та впорядкування всього списку Доменів у даному документі надається офіційний старт для генерації `dive_XX_*.json` артефактів.

## 🏛️ СХЕМА 1: 3 Паралельні Площини Проектування Контексту
У кожному зануренні в **Домен Джерела** отримані **Математичні Проекції** синхронно відображаються на три системні площини:
1. **Площина 1: Хранитель Стану (Memory Vault / ROM)** — збереження JSON-інваріантів у Git (`docs/state_gateway.json`).
2. **Площина 2: Інтерпретатор / Шлюз Подій (Event Bus / Gateway)** — розрахунок джиттеру та телеметрії у реальному часі (`sl8_gateway.js`).
3. **Площина 3: Контур Дій (Action Contour / Master UI)** — відображення на Master Sovereign UI (`docs/index.html`) без порушення фізичної ізоляції.
