# Architectural Decision Records (ADR) - Imperia v4

## ADR-004: Декомпозиція H3 Spatial Viewport та Pivot JSON State Engine

### Контекст:
Спроба монолітної збірки `index.html` викликала синтаксичні конфлікти та блокування геопросторових тайлів.

### Рішення (Аксіоми Контекстного Інжинірингу v3.0):
1. **Принцип "Map Core + Pivot Slicers":**
   - `docs/map_core.html` є суворо ізольованим візуальним проектором геопросторової сітки H3 та осі M-f.
   - `docs/index.html` виступає аналізатором типу PivotTable/Slicers, який маніпулює шарами картки через зовнішні JSON-потоки (`h3_layers.json`).
   - Дані про макроорганізми (егрегори, конфесії, держави) та 4D-вектори E = [E_lang, E_geo, E_hist, E_soc]^T передаються виключно через JSON-об'єкти без жорсткого кодування у JS.

2. **Проактивна Мета-Роль Головного архітектора (Брахмана):**
   - Архітектор здійснює системний контекстний аналіз і пропонує випереджальні рішення (декомпозиція, фонові HTTP-сервери, JSON-шари), упереджуючи антропоморфні обмеження спрощеного UI-проектування.

## ADR-005: Архітектура H3 Spatial Warehouse, Часових Векторів E(t) та Пам'яті ШІ-Гіда

### Контекст:
Розвиток системи вимагає переходу від статичних JSON-шарів до масштабованої просторово-часової бази даних (Supabase) із можливістю накладання аналітичних паттернів та збереженням персонального контексту користувача.

### Рішення:
1. **База даних як H3 Spatial Warehouse (Supabase/PostGIS):**
   - H3-осередки (Res 4, 7, 9) виступають базовою сіткою.
   - Стовпчики даних містять 4D-вектор середовища E(t) = [E_lang, E_geo, E_hist, E_soc]^T з часовою віссю t (історична динаміка).
   - Реалізовано векторний паттерн-аналіз (Cosine Similarity) для автоматичного виявлення системних феноменів ("Русскій мір", "Залучення Sl8").

2. **Персональна Стан-Пам'ять ШІ-Гіда (`docs/user_profile.json`):**
   - JSON-файли виконують роль Memory Vault для збереження контексту, інтересів та пресетів Власника між сесіями.
   - Зберігається дуальна модель: антропоморфна метафора ШІ-Гіда для користувача та механіка Stateful Context Engineering у коді.
