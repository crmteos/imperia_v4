**Кому**: Рольовий Архітектор (`02_architect`) та Рольовий Адміністратор (`05_administrator`)
**Від**: Контекстний Адміністратор (Gemini Notebook, Рівень 2)
**Ціль**: Впровадження Інваріанта Файлової Гігієни, вилучення колізій дублікатів та автоматизація інспекції структури репозиторію.

## 🏛️ 1. Контекстний Маніфест (Context Invariants)

На Контекстному Рівні (Рівень 2) затверджено **Канонічний Інваріант Автономної Гігієни Репозиторію**:

1. **Закон Фізичної Ізоляції каталогу `docs/`**:
   * Каталог `docs/` призначений **ВИКЛЮЧНО для ресурсів веб-інтерфейсу** (`.html`, `.css`, `.js`, зображення, веб-медіа).
   * Будь-які архітектурні специфікації, системні протоколи або текстові звіти (`.md`, `.json` конфіги шлюзу) **НЕ МАЮТЬ ПРАВА перебувати в `docs/`**.
   * Усі виявлені `.md` файли в `docs/` (зокрема дублікат `docs/STATE_GATEWAY_PROTOCOL.md`) підлягають негайній переміщенню до `/.v4_gateway/archive/`.

2. **Розширення функціонала Рольового Адміністратора (`05_administrator.json`)**:
   * Закріпити за іпостассю `05_administrator` функціональні ролі:
     * **Прибиральник (Cleaner)**: Автоматичне виявлення та архівування непрофільних файлів із `docs/`.
     * **Інспектор і Звітник Структури (Structure Inspector)**: Автономне сканування дерева каталогу проєкту та запікання актуального структурованого звіту у файл `/.v4_gateway/out/STATE_CONTEXT_BRIDGE.md`.

## 🛠️ 2. Покроковий Алгоритм Виконання (Level 3 Tasks)

### Крок 1: Оновлення Маніфесту `05_administrator.json`
* Додати до паспорта ролі `/.v4_gateway/roles/manifests/05_administrator.json` обов'язок системної гігієни та сканування файлової структури.

### Крок 2: Очищення каталогу `docs/` та усунення колізій
* Сканувати `docs/` на наявність некоректних файлів системних протоколів.
* Перемістити файл `docs/STATE_GATEWAY_PROTOCOL.md` (та інші аналогічні дублікати) у папку `/.v4_gateway/archive/`.
* Перевірити, що в `docs/` залишилися лише веб-інтерфейси (`index.html`, `kassator.html`, `js/`, `css/`).

### Крок 3: Запікання Телеметрії та Звіту Структури
* Оновити файл `/.v4_gateway/out/STATE_CONTEXT_BRIDGE.md`:
  * Додати актуальне чисте дерево каталогів проєкту.
  * Зафіксувати статус виконання правила гігієни (`docs/ isolation: VERIFIED`).
  * Оновити статус у `master_checklist.md`.

### Крок 4: Фіксація в Git
* Виконати синтаксичну перевірку та статус Git:
  * `git add .`
  * `git commit -m "refactor(hygiene): enforce physical isolation of docs and deploy workspace inspector"`
  * `git push origin main`
