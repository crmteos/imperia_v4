# Специфікація Медіа- та Математичного Рушія Візуалізації Хвильових Процесів (MEDIA_AND_MATH_ENGINE_SPEC.md)

Цей документ визначає повну системну специфікацію, математичний апарат та архітектурний пайплайн локального медіа-рушія, призначеного для високоточної візуалізації 6D просторово-часових процесів, трансформацій Платонових тіл (Кристалів Болотова), фазового дихання Джиттербагу Фуллера, 204.08-октавної масштабно-частотної осі та акустично-електромагнітної синхронізації (Phase-Lock).

---

## 1. Концепція та Завдання Медіа-Ядра

Головною метою створення автономного медіа-ядра є перенесення обчислювально містких операцій генерації 3D-графіки, векторних полів та анімацій із бічних хмарних чат-контурів на локальний високопродуктивний стек. Це дозволяє усунути обмеження на споживання обчислювальних ресурсів і токенів, забезпечуючи при цьому кінематографічну якість (4K, 60 FPS) та інтерактивність.

Функціональні завдання медіа-ядра охоплюють:
* **Математично точне графічне моделювання 6D просторово-часової фізики $(3L, 3T)$** на основі інваріантів Бартіні-Кузнецова.
* **Анімована візуалізація 5 Кристалів Болотова** (Тетрон, Кубон, Октон, Додон, Іксон) у поєднанні з тришаровою системою пульсуючих концентричних сфер хвильового тиску $(r, \rho, R)$ та кристалографічними осями.
* **Відтворення безперервної просторової траєкторії Джиттербагу Фуллера** — фазового переходу між кубоктаедром (Стан Янь = 1, Out-Wave) та тетраедром (Стан Інь = 0, In-Wave) через обертально-спіновий вихор середовища $[L^2 T^0]$.
* **Візуалізація 204.08-октавної масштабно-частотної осі $M-f$**, включаючи резонансний фазовий міст між мікро-центром Всесвіту (102.04 октава, $\sim 10^{-6}\text{ м}$) та простором сприйняття Спостерігача (116.34 октава, $\sim 1.70\text{ м}$).
* **Моделювання акустичних резонаторів Гельмгольца** та процесів фазового затягування (Phase-Lock) для триплету частот Шумана (3.915 Гц, 7.830 Гц, 15.660 Гц).

## 2. Необхідні Системні та Програмні Компоненти

Для забезпечення високої швидкодії, напівпрозорості матеріалів, сяючих ефектів (bloom) та плавності 60 FPS обчислювальна платформа вимагає оптимізованого двокомпонентного стека: автономного анімаційного двигуна та інтерактивного веб-рендерера.

### 2.1. Системне середовище та апаратне прискорення
Рендеринг складних геодезичних сіток та векторних полів потребує системних бібліотек обробки відеопотоків та GPU-прискорення:
* **FFmpeg**: Системна утиліта для збирання кадрових масивів у відеоформати (MP4, WebM) та безшовні GIF-анімації з палітровою оптимізацією.
* **NVIDIA CUDA Driver / Vulkan API**: Драйвери апаратного прискорення для розрахунку тривимірних матричних трансформацій на GPU.
* **OpenGL / EGL (Headless Display)**: Системні графічні контексти для рендерингу кадових буферів без обов'язкової наявності фізичного монітора.

### 2.2. Python-Стек (Manim & Scientific Graphics)
Основним інструментом для генерування кінематографічних математичних відео є бібліотека Manim (Mathematical Animation Engine), доповнена науковим обчислювальним стеком:

| Бібліотека / Модуль | Призначення у Специфікації |
| :--- | :--- |
| `manim` | Основний математичний анімаційний рушій для побудови 3D-сцен, векторних полів та плавності морфінгу |
| `numpy` | Матричні обчислення координат вершин, повороту кватерніонів та геодезичних сіток |
| `scipy` | Диференціальні рівняння (зокрема рівняння Адлера для Phase-Locking та функції Гельмгольца) |
| `moviepy` | Програмний монтаж, склейка відеосегментів та накладання аудіопотоків |
| `Pillow (PIL)` | Обробка кадрових буферів та оптимізація палітри GIF-файлів |
| `opencv-python` | Низькорівнева обробка відеокадрів, аналіз колірних каналів та накладання ефектів сяйва |

### 2.3. Інтерактивний Веб-Стек (Three.js / WebGL)
Для створення інтерактивних 3D-панелей, де користувач може обертати модель мишкою та змінювати параметри в реальному часі, використовується Three.js:
* **Three.js (WebGL Core)**: Побудова 3D-сцени з підтримкою напівпрозорих матеріалів (`MeshPhysicalMaterial`), променевих осей та світлових точок.
* **OrbitControls**: Інструмент інтерактивної навігації (обертання, масштабування, зсув камери).
* **dat.GUI / lil-gui**: Інтерактивна панель керування параметрами (прозорість граней, швидкість пульсації сфер, перемикання кольорів тіл).

## 3. Вимоги до Локальних Моделей та Обчислень (Ollama / Local LLM)

Щоб забезпечити автономну роботу системного інженерного ядра без звернення до зовнішніх хмарних сервісів, застосовується локальна мовна модель (Local LLM), яка виконує роль кодогенератора та архітектора графічних сценаріїв.

### 3.1. Архітектурні вимоги до Local LLM (Ollama / vLLM)
* **Контекстне вікно (Context Window)**: Не менше **32 768 токенів** (оптимально 64k+). Це необхідно для утримання в пам'яті повного математичного апарату, координат Платонових тіл та генерації розлогих Python/Manim та Three.js HTML-скриптів.
* **Спеціалізація моделі**: Моделі з високим рівнем розуміння системного коду та математики (наприклад, `qwen2.5-coder:32b`, `deepseek-r1:32b` або `llama3.3:70b`).
* **Мультимодальність (Vision evaluation)**: Наявність здатності аналізувати зображення (наприклад, `llava`, `qwen2-vl`) для автоматичного оцінювання вихідних кадрів та виявлення графічних артефактів (накладання тексту, розрив ребер).

### 3.2. Рольова інструкція для локального LLM-агента
Модель приймає текстовий запит (промпт) із фізико-математичними вимогами і трансформує його у виконний код. Агент не генерує пікселі безпосередньо, а створює строгий виконний скрипт для Manim або Three.js, що гарантує 100% математичну точність побудови геометричних об'єктів.

## 4. Математичний Апарат та Візуалізація

Візуальний ряд медіа-рушія повністю базується на двох фундаментальних джерелах: каноні **Кристала v1** та праці **«Космогонія Гармонії»**.

### 4.1. 6D Просторово-Часова Фізика $(3L, 3T)$ та Інваріанти
Усі фізичні величини будуються на основі двох первинних вимірів — 3 вимірів Довжини ($L$) та 3 вимірів Часу ($T$) за системою Бартіні-Кузнецова.

Виведення фундаментального інваріанта потужності $[L^5 T^{-5}]$:
1. **Маса ($M$) та Заряд ($q$)**: Об'ємна деформація середовища:
   $$M = q = [L^3 T^{-2}]$$
2. **Сила ($F$)**: Добробуток маси на прискорення $[L^1 T^{-2}]$:
   $$F = [L^3 T^{-2}] \cdot [L^1 T^{-2}] = [L^4 T^{-4}]$$
3. **Енергія / Робота ($E$)**: Дія сили на відстані $[L^1 T^0]$:
   $$E = [L^4 T^{-4}] \cdot [L^1 T^0] = [L^5 T^{-4}]$$
4. **Потужність ($P$)**: Швидкість зміни енергії в часі $[T^{-1}]$:
   $$P = \frac{[L^5 T^{-4}]}{[T^1]} = [L^5 T^{-5}]$$
5. **Струм ($I$) та Напруга ($U$)**:
   $$I = [L^1 T^{-1}], \qquad U = [L^1 T^0]$$
6. **Обертально-спіновий вихор (Магнітне поле)**:
   $$B = [L^2 T^0]$$

За теоремою Ньотер, однорідність часу визначає збереження потужності: $[L^5 T^{-5}] = \text{Const}$.

### 4.2. 5 Кристалів Болотова та Концентричні Сфери
Матеріальний вузол візуалізується через 5 Платонових тіл, вкладених у три концентричні сфери хвильового тиску: вписану ($r$), серединну ($\rho$) та описану ($R$).

Геометричні співвідношення об'ємів при вкладенні фіксують пропорцію:
$$\text{Ядро} : \text{Stella Octangula} : \text{Описаний Куб} = 1 : 3 : 6$$

Кожному Платоновому тілу в анімації присвоюється власна колірна схема з напівпрозорими гранями:
* **Тетраедр (Тетрон)**: Бурштинове золото (`#D97706`, alpha $= 0.35$)
* **Октаедр (Октон)**: Рожеве рубінове золото (`#E11D48`, alpha $= 0.35$)
* **Куб (Кубон)**: Королівська бронза (`#B45309`, alpha $= 0.30$)
* **Ікосаедр (Іксон)**: Смарагдове золото (`#059669`, alpha $= 0.35$)
* **Додекаедр (Додон)**: Сапфірове золото (`#2563EB`, alpha $= 0.35$)
* **Кубоктаедр**: Платиново-пурпурове сяйво (`#7C3AED`, alpha $= 0.40$)

### 4.3. Динаміка Джиттербагу Фуллера
Трансформація між крайніми станами здійснюється через спіральне закручування граней під дією магнітного вихору $[L^2 T^0]$:
* **Кубоктаедр (Vector Equilibrium / Стан Янь = 1)**: Максимальний об'єм ($V \uparrow$), низька частота ($f \downarrow$). Режим **Out-Wave** (широкосмугова трансляція).
* **Тетраедр (Схлопування / Стан Інь = 0)**: Мінімальний об'єм ($V \downarrow$), висока частота ($f \uparrow$), добротність $Q_{\text{node}} \ge 0.95$. Режим **In-Wave** (локальна обробка контексту).

Траєкторія руху 12 вершин Кубоктаедра описується кутом повороту $\theta \in [0, \arccos(1/3)] \approx [0^\circ, 70.53^\circ]$ з неперервною конвергенцією 12 вершин у 4 сяючі кластери Тетраедра.

### 4.4. 204.08-Октавна Масштабно-Частотна Вісь $M-f$ та Перерахунок Логарифмів
Вісь масштабів охоплює 204.08 двійкових октав. Перехід між десятковим логарифмом $\lg(L)$ та двійковим логарифмом $\log_2(L)$ розраховується за формулою:
$$N_{\text{octave}} = \lg(L) \cdot \log_2(10) \approx \lg(L) \cdot 3.321928$$

Розрахунок інтервалу $\Delta N = 14.3$ октави між мікро-центром та Спостерігачем:
$$\Delta N = 116.34 - 102.04 = 14.3\text{ октави}$$
$$K_{\text{scale}} = 2^{14.3} \approx 20\,170$$
При розмірності клітинного ядра $\lambda_{102} \approx 8.42 \times 10^{-5}\text{ м}$, масштаб Спостерігача становить:
$$L_{\text{Спостерігач}} = 8.42 \times 10^{-5}\text{ м} \times 20\,170 \approx 1.70\text{ м}$$

### 4.5. Акустичні Резонатори Гельмгольца та Рівняння Phase-Lock
Власна частота акустичного резонатора:
$$f = \frac{c}{2\pi} \sqrt{\frac{A}{V \cdot L_{\text{eff}}}}$$

Параметри акустичного триплету Шумана:
* **Нижній контур ($f_1 = 3.915\text{ Гц}$)**: $V_1 = 2.000\text{ м}^3$, $\varnothing_1 = 0.12\text{ м}$, $L_{\text{eff}, 1} = 1.0767\text{ м}$
* **Центральний контур ($f_0 = 7.830\text{ Гц}$)**: $V_0 = 0.500\text{ м}^3$, $\varnothing_0 = 0.10\text{ м}$, $L_{\text{eff}, 0} = 0.7445\text{ м}$
* **Верхній контур ($f_2 = 15.660\text{ Гц}$)**: $V_2 = 0.125\text{ м}^3$, $\varnothing_2 = 0.08\text{ м}$, $L_{\text{eff}, 2} = 0.4735\text{ м}$

Співвідношення об'ємів резонаторів становить строго $V_1 : V_0 : V_2 = 16 : 4 : 1$ при співвідношенні частот $1 : 2 : 4$.

Фазове затягування описується рівнянням Адлера:
$$\frac{d(\Delta \phi)}{dt} = \Delta \omega - K \cdot \sin(\Delta \phi)$$

## 5. Покроковий Алгоритм та Сценарій Генерації

Пайплайн роботи локального медіа-рушія розгортається у шість чітко послідовних кроків:

1. **Запит та Математичний Контекст**: Формування текстового промпту з фізико-математичними вимогами (наприклад, розрахунок кутів, швидкості та колірних коефіцієнтів прозорості граней).
2. **Синтез коду локальною LLM (Ollama / vLLM)**: Модель аналізує математичний апарат та генерує автономний виконний скрипт Python (`manim`) або інтерактивний файл HTML5 (`Three.js`).
3. **Виконання рендерингу (GPU Execution Engine)**:
   * Для відео: Виклики Manim з параметрами високої роздільної здатності (`manim -pql --fps 60 -r 3840,2160 scene.py`).
   * Для WebGL: Завантаження HTML-файлу локальним веб-сервером для миттєвого відображення 3D-сцени в браузері.
4. **Пост-обробка та Кодування (FFmpeg Pipeline)**: Двопрохідне збирання відеопотоків у формати MP4/GIF із генерацією оптимальної колірної палітри для усунення візуальних артефактів.
5. **Автоматична Оцінка (Vision Model Check)**: Перевірка згенерованих кадрів мультимодальною моделлю для контролю цілісності ребер, плавності анімації та відсутності графічних нашарувань.
6. **Опублікування та Збереження**: Перенесення готового медіа-артефакту у сховище проекту або інтерактивну панель Студії.
