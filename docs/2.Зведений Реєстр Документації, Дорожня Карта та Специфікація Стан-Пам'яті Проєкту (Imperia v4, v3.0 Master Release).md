##### 2.2. Уроки та Регламент усунення "Антропоморфної Помилки v2.0"

* **Причина помилки** : Спроба вбудувати гуманізований кабінет Дмитра та суверенний адмін-центр Власника в один файл index.html.  
* **Системні наслідки** : Потрійні акордеони, витік JS у текст сторінки, конфлікт стилів Tailwind з плитками Leaflet (max-width: 100%).  
* **Рішення v3.0 (Context Engineering)** :  
* Створено  **Master Sovereign UI (**  **docs/index.html**  **)**  для Власника.  
* Створено  **Kassator Executive Workbench (**  **docs/kassator.html**  **)**  для Дмитра.  
* Зв'язок реалізовано через  **sl8\_gateway.js**  з фоновим потоком TELEMETRY\_STREAM та функціями  **Master Override**  (pauseTenant(), recalibrateQBounds()).

1. **Зчитування Стан-Файла** : Завантаження /workspace/docs/state\_gateway.json для відновлення поточних  \$Q\$ \-факторів та векторів  \$\\vec{E}\$ .  
2. **Зчитування Чеклиста** : Завантаження /workspace/out/master\_checklist.md для перевірки виконання задач.  
3. **Ініціалізація Контекстного Вікна** : ШІ-агент приймає роль  **Principal AI Systems Architect** , спираючись на tz-slate-integration-v3.md та role-context-anthropomorphic-framework.tailored-report.md.
