# Канонічний Маніфест Архітектури: Проєкт Imperia (Ітерація 4) та Парадигма Context Engineering v4.0

## 1. Фундаментальне Розділення Контекстів: Предметна Область vs Парадигма Розробки

Критичним успіхом парадигматичного вирівнювання проєкту є чітке відокремлення змісту системи від методу її побудови. Синхронна наявність цифри «4» у назвах предметного проєкту та архітектурного фреймворку є описовим збігом, який вимагає суворого контекстного розмежування:

### 1.1. Предметний Контур системи: Проєкт «Imperia» (Ітерація 4)
* **Природа сутності:** Предметна область, концептуальна модель, метафізичний та обчислювальний задум автора (четверта масштабна спроба реалізації системи).
* **Сфера відповідальності:**
  * Фізико-математичний апарат: 6D просторово-часова фізика $(3L, 3T)$ Бартіні-Кузнецова, 5 Кристалів Болотова, фазове дихання Джиттербагу Фуллера.
  * Геопросторова кластеризація: 204.08-октавна масштабно-частотна вісь $M-f$ та інтеграція зі сферичною сіткою Uber H3.
  * Теорія когерентності: Розрахунок $Q$-фактора системи, 4D-вектора середовища $\vec{E}$ та ефективної потужності $P_{eff}$.
  * Контекстні бібліотеки (ДІВС): Розширювана матриця знань та хвильових процесів.

### 1.2. Метод Розробки: Парадигма «Context Engineering v4.0»
* **Природа сутності:** Системно-інженерна методологія, протокол організації пам'яті ШІ та архітектура розподіленої праці між агентами.
* **Сфера відповідальності:**
  * **Stateful Environment Protocol:** Відмова від безпам'ятних чат-промптів на користь дискретної файлової пам'яті та системних паспортів.
  * **Автономний Локальний ШІ-контур:** Запуск Ollama з моделлю `qwen2.5-coder` (контекст 32768 токенів) у середовищі VS Code / Cline.
  * **3-Рівнева Шлюзова Архітектура:** Суворе розділення обов'язків між Хмарним Архітектором, Файловим Шлюзом та Локальним Виконавцем.

## 2. Трирівнева Архітектура Розподілу Праці (Multi-Agent Division of Labor)

Для усунення «антропоморфної помилки» та запобігання перевантаженню контекстного вікна система функціонує за трьома чітко ізольованими рівнями:

```
[ РІВЕНЬ 1: Хмарний Архітектор ] ──(Gemini Notebook)
             │
             ▼ 1-Click Relay (Директива у .v4_gateway/in/)
[ РІВЕНЬ 2: Файловий Шлюз ] ──────(.v4_gateway/in/ & out/)
             │
             ▼ Автономна кодогенерація & Pre-Commit Check
[ РІВЕНЬ 3: Локальний Виконавець ] ──(VS Code + Cline + Ollama qwen2.5-coder)
```

1. **Рівень 1 (Хмарний Стратег & Архітектор):**
   * **Середовище:** Gemini Notebook.
   * **Функції:** Аналіз джерел, проектирування математичних моделей, проведення контекстного аудиту, формування стандартизованих `.md` директив.
2. **Рівень 2 (Шлюзовий Контролер & Стан-Пам'ять):**
   * **Середовище:** Папка `.v4_gateway/` у репозиторії проєкту.
   * **Структура:** `.v4_gateway/in/` (вхідні директиви), `.v4_gateway/out/` (виходні паспорти та звіти), `.v4_gateway/archived/` (історія виконання).
3. **Рівень 3 (Локальний Інженер-Виконавець):**
   * **Середовище:** ПК Користувача (Windows 11 x64), VS Code з розширенням Cline, підключеним до безлімітного сервера **Ollama** (`http://localhost:11434`, модель `qwen2.5-coder:latest`).
   * **Функції:** Автономне виконання коду, створення Python-модулів, запуск тестів, контроль Git-комітів.

## 4. Специфікація Математичного Ядра (`core/math_engine/`)

Обчислювальне ядро проєкту Imperia побудовано за модульним принципом у папці `core/math_engine/`:

1. `__init__.py` — Фасадна точка входу ядра.
2. `h3_grid.py` — Модуль просторової H3-кластеризації та мапінгу октав $M_0 \dots M_6$ на роздільну здатність Uber H3 (Res 0...15).
3. `coherence_q.py` — Обчислення динаміки $Q$-фактора ($\frac{dQ}{dt} = \alpha (Q_{target} - Q) - \beta \cdot Jitter + \gamma \cdot Feedback$), класифікація когерентних зон (Зелена $\ge 0.90$, Жовта, Червона) та підрахунок ефективної потужності $P_{eff} = \|\vec{E}\| \times Q$.
4. `vectors_e.py` — 4D-вектор середовища $\vec{E} = [E_{lang}, E_{geo}, E_{hist}, E_{soc}]^T$, нормування компонент у $[0.0, 1.0]$ та реєстр регіональних хабів.
5. `wave_physics.py` — Модуль 6D фізики $(3L, 3T)$, розрахунок інваріанта $[L^5 T^{-5}] = \text{Const}$, траєкторія повороту Джиттербагу Фуллера $\theta \in [0^\circ, 70.53^\circ]$ та рівняння фазового затягування Адлера.
